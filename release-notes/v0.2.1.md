## 墨钥 KeyHub 0.2.1

本次更新把安装路径改为纯英文，并修复了设置页改动无法保存的问题。

### 安装路径改为英文

此前安装目录是 `%LOCALAPPDATA%\墨钥 KeyHub`。中文路径在部分系统、子进程和命令行工具中会被错误解码，因此从本版起：

| 项目 | 旧 | 新 |
|---|---|---|
| 安装目录 | `%LOCALAPPDATA%\墨钥 KeyHub` | `%LOCALAPPDATA%\KeyHub` |
| 主程序 | `keyhub.exe` | `KeyHub.exe` |
| 安装包 | `墨钥 KeyHub_<ver>_x64-setup.exe` | `KeyHub_<ver>_x64-setup.exe` |
| 开始菜单 / 卸载项 | 墨钥 KeyHub | KeyHub |

窗口标题、界面文案和应用数据位置都不变：密钥与 config 仍在 `~/.ssh`，偏好、备份与审计日志仍在 `%APPDATA%\KeyHub`。

**从 0.2.0 及更早版本升级无需手动卸载。** 安装器会在拷贝新文件前静默卸载旧版本，并清理旧的中文安装目录和卸载项，不会出现两份程序并存。旧的中文快捷方式会随卸载移除，新版会按新名称重建；如果之前把快捷方式固定在任务栏或开始菜单，升级后需要重新固定。

### 修复

- **设置页的开关和数字输入现在会真正保存。** 此前所有开关（启动时自动检查更新、启动自检、删除确认、连接前确认、自动加入 ssh-agent、权限自动修复、保存前自动备份、审计日志）以及两个数字项（审计保留天数、连接超时）只改变界面状态，没有写入偏好文件，重启后全部恢复原值。
- **环境自检页面布局修复。** SSH 卡片的完整版本号不再把标题和描述挤成竖排；徽记只显示核心版本，悬停可看完整串。
- **统一按钮高度。** 密钥库的「刷新 / 生成密钥」、SSH Config 的「表单 / 原文 / 备份历史」现在高度一致。

### 下载

| 文件 | 用途 |
|---|---|
| `KeyHub_0.2.1_x64-setup.exe` | Windows 安装包（首次安装或手动升级） |
| `latest.json` / `.sig` | 应用内自动更新使用，无需手动下载 |

系统要求：Windows 10 / 11（x64）。更新包会先用内置公钥校验签名，校验失败不会安装。
