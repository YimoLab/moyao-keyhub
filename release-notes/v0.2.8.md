## 墨钥 KeyHub 0.2.8

本次更新主要修复 config 保存时的指令重复问题，并修正了若干界面细节。

### IdentitiesOnly 不再累积重复

此前每次保存 config，`IdentitiesOnly yes` 都会多出一行：解析器把它当作未识别指令原样保留，渲染时又会在 `IdentityFile` 后自动补一行。反复保存后，config 里会积累出一长串完全相同的指令。

现在 `IdentitiesOnly` 由 `IdentityFile` 统一派生，解析时不再进入额外参数，渲染时也会过滤掉旧数据中的残留。打开并保存一次，已经存在的重复行就会自动收敛为一行。

### 备份历史

config 备份历史抽屉出现纵向滚动条时，「预览 / 回滚 / 删除」三个按钮会被挤到第二行。现在操作区固定不换行，抽屉始终预留滚动条槽位，窄窗口下文件名改为省略号显示，悬停可查看完整名称。

### 其它修复

- 安全中心审计日志中目标为空的行不再错位。
- 类别、结果标签的文字水平垂直居中。
- 侧栏 ssh-agent 状态精简为「已加载 N 把」/「未加载密钥」/「未运行」，完整状态保留在悬停提示中。
- 连接测试成功提示精简为「认证成功」，不再重复说明 Git 托管平台不提供 shell。
