## 墨钥 KeyHub 0.2.2

本次更新改善了页面加载体验，并让更新弹窗展示完整的更新说明。

### 加载骨架屏

- 密钥库、SSH Config、安全中心、连接测试、环境自检与设置页在读取数据时，会先显示与真实布局一致的骨架，不再出现空白区域或孤立的转圈。
- 首次引导扫描已有密钥时同样使用骨架占位。
- 数据返回后平滑切换到真实内容，页面高度不会突然跳动。

### 更新弹窗显示更新内容

- 检查到新版本时，弹窗现在会展示完整的发行说明，包括标题、列表、表格与代码块，内容过长时可在弹窗内滚动查看。
- 发行说明同时用于 GitHub Release 正文和应用内更新弹窗，两处内容保持一致。

### 其他修复

- SSH Config 左侧 Host 搜索框的放大镜图标垂直居中，与密钥库、安全中心的搜索框对齐。

### 下载

| 文件 | 用途 |
|---|---|
| `KeyHub_0.2.2_x64-setup.exe` | Windows 安装包（首次安装或手动升级） |
| `latest.json` / `.sig` | 应用内自动更新使用，无需手动下载 |

系统要求：Windows 10 / 11（x64）。更新包会先用内置公钥校验签名，校验失败不会安装。

从 0.2.0 及更早版本升级时，安装器仍会自动迁移旧的中文安装目录，无需手动卸载。
