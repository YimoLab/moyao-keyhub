## 墨钥 KeyHub 0.2.3

本次更新修复了启动时的空白、SSH Config 保存提示不清晰，以及侧栏环境状态拥挤的问题。

### 启动时不再出现空白页

启动后主区域会立即显示与目标页面结构一致的骨架，而不是先空白一段、等读取完偏好和环境信息才出现内容。顶部面包屑在加载期间显示「加载中…」。

### 配置保存失败时能直接看出问题

- 保存被拒绝时，弹窗会一次列出全部错误，每条都带 Host 别名和修复建议，例如「Host「bad-host」：HostName 含空格。去掉空格，IP 或域名都不能带空格」。
- 校验清单中的每条问题都标出所属 Host，点击可定位到对应 Host 的编辑区。
- 主机名、登录用户、端口、私钥路径等字段会在表单里直接标红并给出改法。
- 保存栏会显示第一条错误的具体内容，不再只说「存在 N 个错误」。

### 侧栏环境状态更整齐

「ssh-agent」等标签不再被过长的状态值挤成两行；状态值改为单行显示、超出省略，悬停可查看完整内容。

### 下载

| 文件 | 用途 |
|---|---|
| `KeyHub_0.2.3_x64-setup.exe` | Windows 安装包（首次安装或手动升级） |
| `latest.json` / `.sig` | 应用内自动更新使用，无需手动下载 |

系统要求：Windows 10 / 11（x64）。更新包会先用内置公钥校验签名，校验失败不会安装。
