## 墨钥 KeyHub 0.2.4

本次更新修复了首次保存手写 SSH config 时的一个关键问题，并让行尾注释导致的校验错误更容易理解和修正。

### 首次接管手写 config 时不再保留旧 Host 段

如果你的 `~/.ssh/config` 是手写的、还没有墨钥托管块，此前保存会把手写内容原样保留，再在文件末尾追加一份托管块。由此带来两个问题：

- 旧段落里的问题（例如 `HostName xxx # 注释`）仍会被保存前校验拦截，而表单里看不出哪里错。
- 即使旧段没有语法问题，OpenSSH 也只会采用先出现的旧段，表单里的修改可能不生效。

现在首次保存会把旧的具体 Host 段替换为托管块，只保留 `Host *` 全局段与段外注释。你的别名、主机名、端口、用户、密钥和备注都会按表单内容写入。

### 行尾注释的提示更明确

OpenSSH 不支持行尾注释，`HostName gitlab.example.com # 备注` 里的 `# 备注` 会被算进主机名。现在遇到这种写法会明确提示「请把注释移到单独一行」，而不是只说「去掉空格」。

### 校验状态不再误显示为通过

校验请求本身失败时，清单会显示「校验暂不可用」，不再把请求失败当成「全部通过」。

### 其他

- 托管块注释不再重复出现「由墨钥管理」。

### 下载

| 文件 | 用途 |
|---|---|
| `KeyHub_0.2.4_x64-setup.exe` | Windows 安装包（首次安装或手动升级） |
| `latest.json` / `.sig` | 应用内自动更新使用，无需手动下载 |

系统要求：Windows 10 / 11（x64）。更新包会先用内置公钥校验签名，校验失败不会安装。
